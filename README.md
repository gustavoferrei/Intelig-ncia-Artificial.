# Inteligência Artificial

### RESUMO

Este repositório contem atividades feitas ao longo da disciplina de Inteligência Artificial.

### LINGUAGENS UTILIZADAS

- Python

### Lista de Exercícios Python

## Objetivo

Praticar, aprofundar e consolidar seus conhecimentos em Python ao resolver uma seleção de 50 exercícios cuidadosamente escolhidos. Eles abrangem desde os conceitos mais básicos da linguagem, como variáveis, estruturas de repetição e funções, até tópicos de nível intermediário, incluindo manipulação de listas, dicionários, módulos e tratamento de exceções.
